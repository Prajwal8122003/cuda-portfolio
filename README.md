# CUDA Portfolio Website

A responsive portfolio/agency-style website built as a class project using HTML and CSS.

## Features
- Responsive layout for desktop, tablet, and mobile
- Hero section and navigation
- Services section
- Team section with social links
- Skills/progress section
- Portfolio section
- About section
- Contact form UI
- Image assets included locally

## Technologies
- HTML5
- CSS3
- Font Awesome

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project Structure
```text
CUDA-Portfolio/
├── index.html
├── index.css
├── assets/
│   ├── images and backgrounds
└── README.md
```
